\section{Preliminaries}

Let \(\mathbf{k}\) be an arbitrary field, fixed throughout.
We   denote by  \(\mathbb{R}\)
either the real line or 
the category induced by the poset \((\mathbb{R},\leq)\).
All functors are covariant.

\subsection{The category of persistence modules}

A \textbf{persistence module} is a functor \(\mathbb{R}\to \mathrm{Vect}(\mathbf{k} )\).

\begin{example}[Important]
Let \(I\subseteq \mathbb{R}\) be an interval.
Define \(\mathbf{k}^I\colon \mathbb{R}\to \mathrm{Vect}(\mathbf{k} )\)
by
\[
t\mapsto \begin{cases}
\mathbf{k} &\text{ if } t\in I\\
\mathbf{0}&\text{ else }
\end{cases}
\qquad\text{and}\qquad
r\to s\; \mapsto \begin{cases}
\mathbf{k}\xrightarrow{\mathrm{Id}} \mathbf{k} &\text{ if } r,s\in I\\
\mathbf{0}&\text{ else }
\end{cases}
\]
on objects and morphisms, respectively.
Here \(\mathbf{0}\) denotes both the zero vector space and the zero map,
respectively.
We call \(\mathbf{k}^I\) the \textbf{interval module} over \(I\).

% \end{figure}

\end{example}

\paragraph{Remark.}
Interval modules are the building blocks of persistence modules.
In fact, one objective of persistence theory is to understand 
persistence modules by decomposing them into interval modules.
However, this is not always possible.
A situation when such a decomposition is   guaranteed is 
when   we work with finite dimentional vector spaces,
that is, if we work over \(\mathrm{vect}(\mathbf{k} )\)
instead of \(\mathrm{Vect}(\mathbf{k} )\).

The   concise definition of persistence module can be expanded to aide 
comprehension.
Let \(V\colon \mathbb{R}\to \mathrm{Vect}(\mathbf{k} )\) be a persistence module.
\begin{itemize} 
\item For each \(t\in \mathbb{R} \) and each arrow \(r\to s\) denote \(V(t)=V_t\) and   \(V(r\to s) = v_s^r\).
\item Since \(V\) is a functor, we have the so-called \textbf{composition law}:
\[
 v_t^s\circ v_s^r = v_t^r\quad\text{ whenever } r\leq s\leq t
\]
and \(V(t\to t) = v_t^t = \mathrm{Id}_{V_t}\).
\end{itemize}
Thus, a persistence module \(V\) is a  family of vector spaces \((V_t)_{t\in \mathbb{R}}\)
together with a family
\((v_t^s \colon V_s\to V_t\mid s\leq t)_{s,t\in\mathbb{R}}\)
of \( \mathbf{k} \)-linear maps 
that satisfy the composition law. 

We got a  set theorical definition from the  categorical one above.
In fact, the  two are equivalent.
We will use the first, but   prefer the notation of the second.

Since persistence modules are functors, we can consider the natural transformations
between them, and since those can be composed (using vertical composition)
we obtain a category.

\begin{defi}
The \textbf{category of persistence modules} is 
\(\mathbf{X} = \mathrm{Fun}(\mathbb{R}, \mathrm{Vect}(\mathbf{k} ))\).
% whose 
% \begin{itemize}
% \item objects are functors \(\mathbb{R}\to \mathrm{Vect}(\mathbf{k} )\), and 
% \item morphisms are natural transformations
% \end{itemize}
%
\end{defi}

Yes, this category is fun.
Concretely,
a morphism of persistence modules \(\alpha\colon U\to V\)
is a family of linear maps 
\((\alpha_r\colon U_r\to V_r)_{r\in \mathbb{R}}\)
such that 
the diagram 
\begin{equation}\label{eq:naturality-morphism-persistence-modules}
\begin{tikzcd}
U_s \arrow[r, "u_t^s"] \arrow[d, "\alpha_s"'] & U_t \arrow[d, "\alpha_t"] \\
V_s \arrow[r, "v_t^s"]                        & V_t                      
\end{tikzcd}
\end{equation}
commutes for all \(s\leq t\),
i.e., \(v_t^s \circ \alpha_s=\alpha_t\circ u_t^s\).

\subsection{The shift functor}


Let \(U\) be a persistence module and fix  any \(t\in \mathbb{R}\).
Define a new persistence module \(U[t]\) by 
\[
% U[t](r)=(U[t])_r = U_{t+r}
% \quad\text{and}\quad 
% U[t](r\to s)=(u[t])_r^s = u_{t+r}^{t+s}
%
U[t](r)  = U_{r+t}
\quad\text{and}\quad 
U[t](r\to s) = u_{r+t}^{s+t}.
\]
We say that \(U[t]\) is a \textbf{shifted module}.
Note that  
$$
U[0]=U
\quad\text{and}\quad
U[t][t'] = U[t+t']
$$
for any \(t,t'\in \mathbb{R}\).
Similarly,
for any morphism of persistence modules \(\alpha\colon U\to V\),
we can define a \textbf{shifted module morphism} \(\alpha[t] = (\alpha_{r+t})_{r\in \mathbb{R}}\).

Suppose we've made two shifts of \(U\), say \(U[s]\) and \(U[t]\), where \(s\leq t\).
We might ask ourserlves: \textit{what is the relationship between these shifted modules?}
In other words, we wonder if there is a canonical natural transformation
\(\alpha\colon U[s]\to U[t]\).
% and in fact there is.
To find out, consider any \(p\to q\) and apply both  \(U[s]\) and \(U[t]\) to this arrow.
We get 
$$
U[s](p\to q)\; =\; U_{p+s}\xrightarrow{u_{q+s}^{p+s}} U_{q+s}
$$
and 
$$
U[t](p\to q) \;=\; U_{p+t}\xrightarrow{u_{q+t}^{p+t}} U_{q+t}.
$$
% Since \(\alpha=(\alpha_r\colon U[s](r) \to U[t](r))_{r\in \mathbb{R}}\) 
Since \(\alpha=(\alpha_r )_{r\in \mathbb{R}}\) 
is determined by its components,
we need to find the vertical arrows 
that make the square
$$
\begin{tikzcd}
U_{p+s} \arrow[r, "u_{q+s}^{p+s}"] \arrow[d, "\alpha_p"'] & U_{q+s} \arrow[d, "\alpha_q"] \\
U_{p+t} \arrow[r, "u_{q+t}^{p+t}"']                       & U_{q+t}                      
\end{tikzcd}
$$
%
commute. 
Set \(\alpha_p = u_{p+t}^{p+s}\) and \(\alpha_{q}=u_{q+t}^{q+s}\).
Then the composition law give us 
\[
u_{q+t}^{p+t} \circ  u_{p+t}^{p+s} = u_{q+t}^{p+s} = u_{q+t}^{q+s}\circ u_{q+s}^{p+s},
\]
which means the square commutes.
So, yes there is a canonical way to map \(U[s]\) to \(U[t]\).
Denote \(\alpha = U[s\to t]\) and define  
$$
U[s]\xrightarrow{U[s\to t]} U[t]\;\; = \;\;\left( u_{r+t}^{r+s} \right)_{r\in \mathbb{R}}.
$$



\begin{remark}\hfill\null
\begin{itemize}
% \item We can generalize this construction to define (THIS FOR LATER)
\item For \(t\geq 0\), we denote 
$
\mathds{1}^{t}_U = U[0\to t]
$.
% In fact, we have 
% $$
% \phi \circ \mathbb{1}^{t}_U = \phi = \mathbb{1}^{t}_U \circ \phi
% $$
% for any \(\phi\colon U\to U\) module morphism.

\item Observe that $$
\mathds{1}^{0}_U = U[0\to 0] = (u_r^r)_{r\in \mathbb{R}} 
= (\mathrm{Id}_{U_r})_{r\in \mathbb{R}}
=\mathds{1}_{U}
$$
is an identity natural transformation.
So, for \(t\geq 0\), we might think of \(\mathds{1}^{t}_U\)
as a generalized identity.

\item By definition, we get \(U[t\to t] = \mathds{1}_{U[t]}\) for any \(t\in \mathbb{R}\).
Moreover, if \(r\leq s\leq t\), for any \(p\in \mathbb{R}\) we have
\begin{align*}
\left( U[s\to t] \circ U[r\to s] \right)_p &= U[s\to t]_p \circ U[r\to s]_p\\
&= u_{p+t}^{p+s} \circ u_{p+s}^{p+r}\\
&= u_{p+t}^{p+r}\\
&= U[r\to t]_p
\end{align*}
thanks to the composition law. Thus 
$$
U[s\to t] \circ U[r\to s] = U[r\to t].
$$
\end{itemize}
\end{remark}

The last remark leads us to the following definition.

\begin{defi}
The \textbf{shift functor} \(T = [\,\cdot\,]\colon \mathbb{R}\to \mathrm{End}(X)\) 
is defined as follows
\begin{enumerate}[label=(\roman*)]
\item Objects: for each \(t\in \mathbb{R}\) we have a functor  \(T(t) \colon X\to X\) denoted  \(T_t\), which is defined by \(T_t( U) = U[t]\) on objects \(U\in X\), and by \(T_t(\alpha) = \alpha[t] = (\alpha_{r+t})_{r\in \mathbb{R}}\) on morphisms \(\alpha=(\alpha_r)_{r\in \mathbb{R}}\). %(Equivalently, we can define \(T_t(\alpha) = \alpha \star [t]\), using a whiskering)
\item Morphisms: for each \(r\to s\), define    a natural transformation $T(r\to s)\colon T_r\to T_s$ by
$$
T(r\to s) = \left( U[r\to s] \right)_{U\in X}.
$$
\end{enumerate}
\end{defi}

\begin{example}\label{ex:shifted.interval.module}
Let \(\mathcal{I}=\mathbf{k}^I\) be an interval module 
and fix \(t\in \mathbb{R}\).
Then, for any \(r\in \mathbb{R}\),
$$
% \mathcal{I}[t](r) = 
\mathbf{k}^I(r+t) = \begin{cases}
\mathbf{k} &\text{ if }r+t\in I\\
\mathbf{0}&\text{ else }
\end{cases}
= 
\begin{cases}
\mathbf{k} &\text{ if }r \in I-t\\
\mathbf{0}&\text{ else }
\end{cases}
=
\mathbf{k}^{I-t}(r)
$$
and similarly, for any \(r\leq s\) we obtain $$ \mathbf{k}^I(r+t\to s+t) = \mathbf{k}^{I-t}(r\to s).$$
Thus $\mathbf{k}^I[t] =  \mathbf{k}^{I-t}$.
We will denote \(\mathcal{I}[t]=\mathcal{I}-t\).
\end{example}

\subsection{The interleaving distance between persistence modules}

Let \(U\) and \(V\) be persistence modules.
A \(t\)-\textbf{interleaving} of \(U\) and \(V\) is a pair of   natural transformations
\((\phi\colon U\to V[t], \; \psi\colon V\to U[t] )\)
that make the   diagrams 
$$
\begin{tikzcd}
U \arrow[rd, "\phi"'] \arrow[rr, "\mathbb{1}^{2t}_U"] &                                 & {U[2t]} & V \arrow[rd, "\psi"'] \arrow[rr, "\mathbb{1}^{2t}_V"] &                                 & {V[2t]} \\
                                                      & {V[t]} \arrow[ru, "{\psi[t]}"'] &         &                                                       & {U[t]} \arrow[ru, "{\phi[t]}"'] &        
\end{tikzcd}
$$
commute.
If such a pair exists, we say that \(U\) and \(V\) are \(t\)-\textbf{interleaved}.

\begin{example}
Two persistence modules are isomorphic if and only if they are \(0\)-interleaved.
Thus, we can think of interleavings as generalized isomorphisms.
Let us see why...
\end{example}

\begin{defi}
The  \textbf{interleaving distance} 
between two persistence modules \(U\) and \(V\) is
\[
d_T (U, V)=\inf \left\{t\geq 0 \mid \text {there exists a } t\text {-interleaving of } U \text { and } V\right\}.
\]
in case there is at least one interleaving of \(U\) and \(V\).
If no such interleaving exists, we set 
$d_T (U, V)= \infty$ .
\end{defi} 
% This is the smallest shift we'd need to do for...

The subscript  \(T\) remind us that \(d_T\)
depends on the shift functor.
On the other hand, 
\(d_T\) is not an actual metric, but a \textit{pseudometric}, 
since $d_T (U, V)=0 $  does not imply \(U = V\).

\end{example}

\section{The computation}

We'll do the computation
of $d_T(\mathbf{k}^I,\mathbf{k}^J) $ 
 for the case of closed intervals.
Let \(I=[a,b]\) and \(J=[c,d]\).
Denote by  $\mathcal{I}=\mathbf{k}^I$ and $\mathcal{J}=\mathbf{k}^J$   the associated 
interval modules.

Our strategy is  to find some apropriate bounds for $d_T (U, V)$.
Befor going into the search for the pair of morphisms 
that would make the triangles above commute,
we need to know how are the morphisms between arbitrary interval modules,
because then we can characterize the morphisms between
shifted interval modules.

% Suppose \(I\) and \(J\) are as in the following picture.
Let \(\alpha\colon \mathcal{I}\to \mathcal{J}\)
be any persistence module morphism.
For each \(s\in \mathbb{R}\)
we have a map of vector spaces 
$\alpha_s \colon \mathcal{I}_s\to \mathcal{J}_s$.
The only available options for \(\mathcal{I}_s\) and \(\mathcal{J}_s\)
are either \(\mathbf{k}\) or \(\mathbf{0}\).



\begin{figure}[H]
    \centering
    \includegraphics[width=0.75\linewidth]{../assets/media/morphism_interval_modules.png} 
\end{figure}

Note that, if \(s\notin I\cap J\), then either 
\(\mathcal{I}_s=\mathbf{0}\) or \(\mathcal{J}_s=\mathbf{0}\),
and in any case \(\alpha_s\) is the zero map.
Thus, we always get trivial morphisms outside of the intersection.
Inside the intersection, when \(s\in I\cap J\), we have
a linear map \(\alpha_s\colon \mathbf{k}\to \mathbf{k}\),
but since \(\mathbf{k}\) is a field, 
\(\alpha_s\) is nothing more than multiplication by some scalar \(\lambda\in \mathbf{k}\), so \(\alpha_s\colon x\mapsto \lambda x\).
Such \(\lambda\) could be zero, though.

As a first result, we have the following.

\paragraph{Fact 1.} If \(I\cap J=\varnothing\), then \(\mathrm{Hom}(\mathbf{k}^I, \mathbf{k}^J) = \mathbf{0}\).
\bigskip

With this trivial case out of the way, assume \(I\cap J\neq \varnothing\),
and  let us consider 
two cases: \(a < c\) or \(c\leq a\).

\begin{enumerate}[label=(\roman*),left=1cm]
\item[\textbf{Case 1.}] Suppose \(a < c\). 
Recall that our goal is to characterize
the morphisms \(\mathbf{k}^I \to \mathbf{k}^J\).
Since we already know what happens when \(t\notin I\cap J\),
let us focus on \(\alpha_t\colon \mathbf{k}^I_t \to \mathbf{k}^J_t\) 
with  \(t\in I\cap J\),
that is with \(c\leq t\leq b\).
\begin{figure}[H]
\centering
\includegraphics[width=0.75\linewidth]{../assets/media/case-a-less-than-c.png}
\end{figure}
Take the arrow \(a\to t\) and apply both 
\(\mathbf{k}^I\) and \(\mathbf{k}^J\).
We have  \(\mathbf{k}^I(a\to t) = \mathbf{k}\xrightarrow{\mathrm{Id}} \mathbf{k}\)
and 
\(\mathbf{k}^J(a\to t) = \mathbf{0}\xrightarrow{\mathrm{0}} \mathbf{k}\).
Note that \(\alpha_a\colon \mathbf{k}\to \mathbf{0}\) is the zero map
and \(\alpha_t\colon \mathbf{k}\to \mathbf{k}\)
is some linear map.
By \eqref{eq:naturality-morphism-persistence-modules}, naturality implies
$$
\alpha_t =  \alpha_t\circ \mathbf{k}^I(a\to t) 
= \mathbf{k}^J(a\to t)\circ \alpha_a = 0.
$$
Thus \(\alpha_t\) is zero even on \(I\cap J\).
The conclusion  is that 
$\mathrm{Hom}(\mathbf{k}^I, \mathbf{k}^J)\cong \mathbf{0} $
%  if \(I\cap J\neq \varnothing\).
if \(I\) was \textit{born} before \(J\).

\item[\textbf{Case 2.}] Suppose \(c\leq a\), meaning that \(J\) was \textit{born} before \(I\). Now we consider two more cases.
\item[\textbf{Case 2.1.}] Suppose \(b <d\). This means that \(J\) \textit{died} after \(I\).
We also get $\mathrm{Hom}(\mathbf{k}^I, \mathbf{k}^J)\cong \mathbf{0} $.
\item[\textbf{Case 2.2.}] Suppose $d\leq b $. Here we prove there is an isomorphism $\mathrm{Hom}(\mathbf{k}^I, \mathbf{k}^J)\cong \mathbf{k} $.
\end{enumerate} 

Now we come to the following conclusion.

\paragraph{Fact 2.} If  \(c\leq a\leq d\leq b\), 
then   $\mathrm{Hom}(\mathbf{k}^I, \mathbf{k}^J)\cong \mathbf{k} $.
Given \(\lambda\in \mathbf{k}\),
define $\alpha^\lambda \colon \mathbf{k}^I\to \mathbf{k}^J  $ 
by 
$$
\alpha^\lambda_r =
\begin{cases}
\mathbf{k}\xrightarrow{\mu_\lambda}\mathbf{k}
&\text{if } r\in I\cap J\\
\mathbf{k}^I_r\xrightarrow{0}\mathbf{k}^J_r&\text{else}
\end{cases}
$$
where \(\mu_\lambda\colon r\mapsto \lambda r\).
The map $$\Psi \colon \mathbf{k}\to \mathrm{Hom}(\mathbf{k}^I, \mathbf{k}^J):\lambda\mapsto \alpha^\lambda$$
is injective, and 
surjective, and linear
(proof...)
\bigskip

Both Fact 1 and Fact 2 will help us determine \(d_T(\mathbf{k}^I, \mathbf{k}^J)\)
for any closed intervals \(I\) and \(J\).
\subsection{Bound above}

We start looking for values of \(t\geq 0\) 
for which a \(t\)-interleaving of 
\({\mathcal{I}}=\mathbf{k}^I\) and \({\mathcal{J}}=\mathbf{k}^J\)
exists, that is,
for which we can find maps 
$ \phi\colon {\mathcal{I}}\to {\mathcal{J}}[t]$ and $ \psi\colon {\mathcal{J}}\to {\mathcal{I}}[t]   $ 
that make the diagrams
$$
\begin{tikzcd}[column sep={1.4em}]
{\mathcal{I}} \arrow[rd, "\phi"'] \arrow[rr, "\mathds{1}^{2t}_{{\mathcal{I}}}"] &                                 & {{\mathcal{I}}[2t]} & {\mathcal{J}} \arrow[rd, "\psi"'] \arrow[rr, "\mathds{1}^{2t}_{{\mathcal{J}}}"] &                                 & {{\mathcal{J}}[2t]} \\
                                                      & {{\mathcal{J}}[t]} \arrow[ru, "{\psi[t]}"'] &         &                                                       & {{\mathcal{I}}[t]} \arrow[ru, "{\phi[t]}"'] &        
\end{tikzcd}
$$
commute.
By using the fact that a shift of an interval module is 
the interval module of the shifted interval (Example \ref{ex:shifted.interval.module}),
we can redraw these diagram as 
% we want 
%
% such that the diagrams
$$
\begin{tikzcd}[column sep=1.25em]
{\mathbf{k}^{[a,b]}} \arrow[rd, "\phi"'] \arrow[rr, "{{\mathbf{k}^{[a,b]}[0\to 2t]}}"] &                                 & {{\mathbf{k}^{[a-2t,b-2t]}}} & {\mathbf{k}^{[c,d]}} \arrow[rd, "\psi"'] \arrow[rr, "{{\mathbf{k}^{[c,d]}[0\to 2t]}}"] &                                 & {{\mathbf{k}^{[c-2t,d-2t]}}} \\
                                                      & {{\mathbf{k}^{[c-t,d-t]}}} \arrow[ru, "{\psi[t]}"'] &         &                                                       & {{\mathbf{k}^{[a-t,b-t]}}} \arrow[ru, "{\phi[t]}"'] &        
\end{tikzcd}
$$

The first observation is that if the top arrows are both \(0\), 
then we can put \(\phi=0\) and \(\psi=0\) because then 
the triangles commute trivially.
But, how do we get the top arrows to be zero?
Here we can use Fact 1: if \([a,b]\cap [a-2t,b-2t]=\varnothing\), then 
\(\mathrm{Hom}(\mathbf{k}^{[a,b]}, \mathbf{k}^{[a-2t,b-2t]}) = \mathbf{0}\).
In order to get an empty intersection, 
we just need to make a sufficiently large shift.
Since \(t\geq 0\), the shift moves to the left,
so we need \(b-2t < a\), 
that is \(t> \frac{b-a}{2}\).
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\linewidth]{../assets/media/intervalAB-empty-intersection.png}
% \caption{}%\label{fig:}
\end{figure}
By the same reason we arrive at 
\(t> \frac{d-c}{2}\).
Thus the top arrows are both zero if \(t> \frac{b-a}{2}\) and \(t> \frac{d-c}{2}\), 
which is equivalent to 
$$
t>\frac{1}{2}\max\left\{ b-a,d-c \right\}.
$$
If we denote the right term by \(M\), 
we get that an \((M+\varepsilon)\)-interleaving of \(\mathcal{I}\) and \(\mathcal{J}\)
exists for every \(\varepsilon > 0\).
Thus $d_T(\mathbf{k}^I, \mathbf{k}^J) \leq M+\varepsilon$  for every \(\varepsilon > 0\),
and taking the infimum over \(\varepsilon\) give us 
$$
d_T(\mathbf{k}^{[a,b]}, \mathbf{k}^{[c,d]}) \leq \frac{1}{2}\max\left\{ b-a,d-c \right\}.
$$
Notice that this bound does not take into account the relationship (or position)
between \(I\) and \(J\),
so our next step is to find a bound that 
does consider this aspect.

Now we use Fact 2.
Framed in our context, it tell us that 
\begin{equation}\label{eq:inequalities-for-non-trivial-hom}
\begin{aligned}
c-t\leq a \leq d-t\leq b &\implies \mathrm{Hom}(\mathbf{k}^{[a,b]}, \mathbf{k}^{[c-t,d-t]})\cong \mathbf{k} \\
a-t\leq c \leq b-t\leq d &\implies \mathrm{Hom}(\mathbf{k}^{[c,d]}, \mathbf{k}^{[a-t,b-t]})\cong \mathbf{k} .
\end{aligned} 
\end{equation}
Now we start looking for values of \(t\geq0\)
for which the two sets of inequalities
are satisfied, because then we can choose 
apropriate
nonzero \(\phi\) and \(\psi\)
such that \((\phi,\psi)\) is  a \(t\)-interleaving.

The conditions $ c-t\leq a$ and $ a-t\leq c$ are equivalent to 
$t\geq  |c-a| $, 
and the conditions 
$ d-t\leq b$ and $ b-t\leq d$ are equivalent to 
$t\geq  |d-b| $.
So, let \(t\geq\max\{|c-a|,|d-b|\}\).

With respect to the middle inequalities,  
we consider two cases.
\begin{enumerate}[label=(\roman*),left=1cm]
\item[\textbf{Case A.}] 
Suppose \(d-t < a\) and \(b-t<c\).
% From \(d-t < a\), 
Using the fact that  \(t\geq |d-b|\geq b-d\), we have
$$
b-2t = b -t -t \leq b-(b-d)-t \leq d-t < a
$$
% $$
% b-d\leq t \implies b-t< d \implies b-2t\leq d-t < a
% $$
whence $t > \frac{b-a}{2}$.
Similarly, if \(b-t < c\), we get \(t> \frac{d-c}{2}\).
Thus \(t\geq \max\{\frac{b-a}{2},\frac{d-c}{2}\}\),
which lead us to the situation above where 
a \(t\)-interleaving trivially exists,
but the two hom-sets are zero.

\item[\textbf{Case B.}]
Suppose then that \(a\leq d-t\) or \(c\leq b-t\).
Using the assumption that \(t\geq\max\{|c-a|,|d-b|\}\),
we see that either inequality implies the other.
Thus we have  \(a\leq d-t\) and \(c\leq b-t\).
Therefore both sets of inequalities in \eqref{eq:inequalities-for-non-trivial-hom} above are satisfied,
whence
% The middle inequalities translate into 
% \(t\leq \min\{d-a,b-c\}\).
% Thus, if $t\geq \max\{|c-a|,|d-b|\} $,
% we have 
$$
\mathrm{Hom}(\mathbf{k}^{[a,b]}, \mathbf{k}^{[c-t,d-t]})\cong \mathbf{k} 
\quad\text{and}\quad 
\mathrm{Hom}(\mathbf{k}^{[c,d]}, \mathbf{k}^{[a-t,b-t]})\cong \mathbf{k}.
$$
Using Fact 2, 
we see that
this implies that 
for \(1\in \mathbf{k}\), 
there exists 
\(\phi\colon \mathbf{k}^{[a,b]}\to \mathbf{k}^{[c-t,d-t]}\)
and 
\(\psi\colon \mathbf{k}^{[c,d]}\to \mathbf{k}^{[a-t,b-t]}\) defined by 
$$
\phi_r = %\colon x\mapsto 1\cdot x
\begin{cases}
\mathbf{k}\xrightarrow{\mathrm{Id}}\mathbf{k}
&\text{if } r\in [a,d-t]\\
\mathbf{0}&\text{else}
\end{cases}
$$
and 
$$
\psi_r = %\colon x\mapsto 1\cdot x
\begin{cases}
\mathbf{k}\xrightarrow{\mathrm{Id}}\mathbf{k}
&\text{if } r\in [c,b-t]\\
\mathbf{0}&\text{else}
\end{cases}
$$
The final, and most important, step is to prove 
that \((\phi,\psi)\) is a \(t\)-interleaving of \(\mathbf{k}^I \) and $\mathbf{k}^J $.
This amounts to prove that the 
triangles 
$$
\begin{tikzcd}[column sep=1em]
{\mathbf{k}^{[a,b]}_r} \arrow[rd, "\phi_r"'] \arrow[rr, "{{\mathbf{k}^{[a,b]}(r\to  r+2t)}}"] &                                 & {{\mathbf{k}^{[a-2t,b-2t]}_r}} & {\mathbf{k}^{[c,d]}_r} \arrow[rd, "\psi_r"'] \arrow[rr, "{{\mathbf{k}^{[c,d]}(r\to r+2t)}}"] &                                 & {{\mathbf{k}^{[c-2t,d-2t]}_r}} \\
                                                      & {{\mathbf{k}^{[c-t,d-t]}_r}} \arrow[ru, "{\psi_{r+t}}"'] &         &                                                       & {{\mathbf{k}^{[a-t,b-t]}_r}} \arrow[ru, "{\phi_{r+t}}"'] &        
\end{tikzcd}
$$
commute for every \(r\in \mathbb{R}\).
Let's consider the first triangle.
We consider three cases.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.75\linewidth]{../assets/media/nonzero-regions-interleaving.png}
\end{figure}
If \(r\in (-\infty,a)\),
then 
% \(\phi_r = \mathbf{0}\xrightarrow{\mathrm{0}}\mathbf{k}\)
% and 
% $ \mathbf{k}^{[a,b]}(r\to  r+2t) = \mathbf{0}\xrightarrow{\mathrm{0}}\mathbf{k}$.
% Thus 
\begin{align*}
\psi_{r+t}\circ \phi_r 
&= \psi_{r+t}\circ (\mathbf{0}\xrightarrow{\mathrm{0}}\mathbf{k^*})\\
&= \mathbf{0}\xrightarrow{\mathrm{0}}\mathbf{k^*}\\
&= \mathbf{k}^{[a,b]}(r\to  r+2t)
\end{align*}
no matter the value of \(\psi_{r+t}\).
Here  \(\mathbf{k^*}\) denotes either \(\mathbf{0}\) or \(\mathbf{k}\).

If \(r\in[a,b-2t]\),
then 
% \(\phi_r = \mathbf{k}\xrightarrow{\mathrm{Id}}\mathbf{k}\),
% $\psi_{r+t} = \mathbf{k}\xrightarrow{\mathrm{Id}}\mathbf{k} $ 
% and 
% $ \mathbf{k}^{[a,b]}(r\to  r+2t) = \mathbf{k}\xrightarrow{\mathrm{Id}}\mathbf{k} $.
% Thus 
% $$
% \psi_{r+t}\circ \phi_r = \mathrm{Id} =  \mathbf{k}^{[a,b]}(r\to  r+2t)
% $$
% xd 
\begin{align*}
\psi_{r+t}\circ \phi_r &= 
(\mathbf{k}\xrightarrow{\mathrm{Id}}\mathbf{k}) \circ (\mathbf{k}\xrightarrow{\mathrm{Id}}\mathbf{k})\\
&= \mathbf{k}\xrightarrow{\mathrm{Id}}\mathbf{k}\\
&= \mathbf{k}^{[a,b]}(r\to  r+2t).
\end{align*}
Finally, 
if \(r\in(b-2t,\infty)\),
\begin{align*}
\psi_{r+t}\circ \phi_r &= 
(\mathbf{k^*}\xrightarrow{\mathrm{0}}\mathbf{0}) \circ \phi_r\\
&= \mathbf{k^*}\xrightarrow{\mathrm{0}}\mathbf{0}\\
&= \mathbf{k}^{[a,b]}(r\to  r+2t).
\end{align*}
where \(\mathbf{k^*}\) denotes either \(\mathbf{0}\) or \(\mathbf{k}\).
We have proved that   the left triangle commutes
for every \(r\in \mathbb{R}\).
In an entirely analogous manner we prove the 
right triangle commutes.
Therefore \((\phi,\psi)\)   is a \(t\)-interleaving of \(\mathbf{k}^{I}\) and 
$\mathbf{k}^J $. 
\end{enumerate}
We have proved that, in either case A or B, 
\(\mathbf{k}^{I}\) and 
$\mathbf{k}^J $
are \(t\)-interleaved
if \(t\geq\max\{|c-a|,|d-b|\}\).
Therefore 
$$
d_T(\mathbf{k}^{[a,b]}, \mathbf{k}^{[c,d]}) \leq  \max\left\{ |c-a|,|d-b|\right\}.
$$
Up to now we've found two upper bounds for $d_T(\mathbf{k}^{[a,b]}, \mathbf{k}^{[c,d]}) $, so we know 
that  the distance is smaller than both of them.
We summarize what we've found in the following
\paragraph{Fact 3.} 
For any closed intervals \(I=[a,b]\) and $J=[c,d] $,
\begin{equation}\label{eq:upper-bounds}
d_T(\mathbf{k}^{[a,b]}, \mathbf{k}^{[c,d]}) \leq \min\left\{ \frac{1}{2}\max\left\{ b-a,d-c \right\},\max\left\{ |c-a|,|d-b|\right\}\right\}.
\end{equation}

\subsection{Bound below}

Let's prove that \eqref{eq:upper-bounds}
is actually an equality.
Denote that minimum by \(m\).
Our goal is to prove that if 
a \(t\)-interleaving exists, then 
necessarily \(t\geq m\),
for then we can take the infimum over all 
those \(t\geq 0\) and get that \(  d_T(\mathbf{k}^{[a,b]}, \mathbf{k}^{[c,d]})\geq m\).

Let \(t\geq0\).
We will actually prove that if \(t<m\), then no interleaving can exists.
